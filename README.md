## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Dvicttor/liguagens_de_programa
```

2. Acesse a pasta:

```bash
cd liguagens_de_programa
```

3. Execute um arquivo Python:

```bash
python nome_do_arquivo.py
```
